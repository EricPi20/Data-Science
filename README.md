# Data-Science

## Scientific Calculator

Ahoy! This repository contains two versions of a scientific calculator:

### 🌐 Web Version (`scientific_calculator.html`)
A modern, beautiful web-based scientific calculator that works in any browser.

**To use:**
- Simply open `scientific_calculator.html` in your web browser
- No installation required!
- Features keyboard support for quick calculations

**Features:**
- Basic arithmetic operations (+, -, ×, ÷)
- Trigonometric functions (sin, cos, tan, asin, acos, atan)
- Logarithmic functions (log, ln)
- Exponential functions (e^x, x^y)
- Square root (√)
- Factorial (n!)
- Constants (π, e)
- Memory functions (MC, MR, M+, M-)
- Percentage calculations
- Parentheses support

### 🐍 Python GUI Version (`scientific_calculator.py`)
A desktop application built with Python's tkinter library.

**To use:**
```bash
python3 scientific_calculator.py
```

**Requirements:**
- Python 3.x
- tkinter (usually included with Python)

**Features:**
- All the same features as the web version
- Native desktop application
- Keyboard shortcuts supported
